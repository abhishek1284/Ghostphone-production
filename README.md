# GhostPhone Product Hunt - QA Test Cases

## Project Overview

This repository contains manual test cases created for the GhostPhone launch page on Product Hunt.

The objective of this testing effort is to validate the functionality, usability, responsiveness, performance, and user experience of the GhostPhone product launch page.

## Test Scope

The following modules were covered:

* Launch Page Verification
* Navigation
* Product Details
* Product Description
* Media (Images & Videos)
* Upvote Functionality
* Comments
* Social Sharing
* External Website Redirection
* UI/UX Validation
* Responsiveness
* Performance
* Session Management
* Error Handling
* SEO Validation
